# Contributing to Inv-Wave Lab

Thanks for helping improve Inv-Wave Lab. This project is experimental research software, so clarity matters as much as code.

## Workflow

1. Fork the repository.
2. Create a focused feature branch.
3. Keep changes scoped and explain any model assumption changes.
4. Run `npm test`.
5. Open a pull request with context, screenshots for UI changes, and backtest evidence when model behavior changes.

## Good Contribution Areas

- Backtest quality and edge cases.
- Clearer risk and confidence explanations.
- Additional data adapters.
- Accessibility and responsive design.
- Documentation and examples.

## Reminder

Inv-Wave Lab is not financial advice or an execution system. Please avoid framing model output as guaranteed investment performance.
